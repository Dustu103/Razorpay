# Architecture Decision Records (ADR)

> An ADR captures a significant architectural decision made during the project, along with the context, options considered, and consequences. They are **immutable** — once accepted, an ADR is never edited, only superseded by a new one.

## Status Definitions
- **Proposed** — Under discussion, not yet implemented.
- **Accepted** — Decision made and implemented.
- **Deprecated** — Was valid but no longer applies.
- **Superseded** — Replaced by a newer ADR (link provided).
